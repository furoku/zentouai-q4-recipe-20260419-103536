# お気に入りレシピ帳

平日の食事を選びやすくする、1ページ完結の静的レシピサイトです。調理時間、材料、ひとことポイントを先に確認できる構成を試しています。

**Live site:** https://zentouai-q4-recipe-20260419-103536.vercel.app/

## 掲載しているレシピ

- ツナと大葉の和風パスタ
- 鶏むね肉の甘酢炒め
- 豆腐とわかめの味噌汁

## ステータス

このリポジトリは、情報量の少ない題材を読みやすいWebページへまとめるための**静的UI実験**です。レシピの検索、保存、投稿、会員登録などの機能はありません。

## 構成

```text
.
├── index.html   # HTML・CSSを含むサイト本体
└── README.md    # この説明
```

外部ライブラリやビルド工程は使用していません。

## ローカルで見る

`index.html` をブラウザで直接開くか、リポジトリのルートで静的サーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://127.0.0.1:8000/` を開いてください。
